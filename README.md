# The 29 · อัปเดตกฎหมายและราคาก่อสร้าง

สรุปกฎหมายควบคุมอาคารใหม่ทุกจันทร์และศุกร์ ตารางค่ากำหนดที่ใช้บ่อย ดัชนีราคา และราคาวัสดุจาก สนค. กับร้านวัสดุ 5 ร้าน

- หน้าเว็บ: `index.html` (GitHub Pages)
- ข้อมูล: Supabase (ตาราง `docs` อ่านได้สาธารณะ, `feedback` ส่งได้อย่างเดียว)
- ทุกรายการมีลิงก์ไปต้นฉบับ — เปิดตรวจกับต้นฉบับก่อนอ้างอิงในงาน
